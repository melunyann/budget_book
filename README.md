# おかねびより

バイトのシフトと家計簿を、ひとつのカレンダーで管理する自分用ミニアプリです。
サーバーやビルド不要、`index.html` を開くだけで動きます。データはブラウザの localStorage に保存されます（自分の端末だけに保存されるので、他の人には見えません）。

## できること

- **月カレンダー / 週カレンダー**：シフトのある日・給料日・家計簿の入力がある日がひと目でわかる
- **シフト入力 → 自動で給料計算**：開始・終了時刻と休憩時間、時給からその日の給料を自動計算
- **給料日の自動算出**：「◯日締め・◯ヶ月後の◯日払い」を設定すれば、シフトを入れるだけで給料日とその日にもらえる金額を自動でまとめて表示
- **家計簿**：収入・支出をカテゴリ別に記録。月ごとの収支や支出の内訳をグラフっぽいバーで確認
- **データのバックアップ**：設定画面からJSONで書き出し・読み込みができます

## GitHub Pages での公開方法

1. GitHubで新しいリポジトリを作成する（例：`okane-biyori`）
2. このフォルダの中身（`index.html`, `app.js`, `README.md`）をリポジトリのルートに置いて push する

   ```bash
   git init
   git add .
   git commit -m "add okane-biyori app"
   git branch -M main
   git remote add origin https://github.com/【あなたのユーザー名】/okane-biyori.git
   git push -u origin main
   ```

3. GitHubのリポジトリページで **Settings → Pages** を開く
4. 「Build and deployment」の **Source** を `Deploy from a branch` にし、Branch を `main` / `/(root)` に設定して **Save**
5. 数分待つと `https://【あなたのユーザー名】.github.io/okane-biyori/` でアクセスできるようになります

> ローカルで試したいだけなら `index.html` をブラウザでダブルクリックして開くだけでOKです。

## 最初にやること

アプリを開いたら、まず **「設定」タブ** で以下を自分のバイト先に合わせて設定してください。

- 基本の時給
- 締め日（例：月末、15日など）
- 支払いのタイミング（同じ月／翌月／翌々月）と支払日

設定すると、その下に計算ルールのプレビューが出るので確認してから「この内容で保存する」を押してください。

## データについて

- データは端末のブラウザ内（localStorage）だけに保存されます。ブラウザのデータを消去すると失われるので、たまに設定画面から「JSONで書き出す」でバックアップしておくと安心です
- スマホとPCなど複数端末で使いたい場合は、書き出したJSONをもう一方の端末で「JSONを読み込む」から読み込んでください（自動同期はしません）

## カスタマイズのヒント

- 収入・支出のカテゴリは `app.js` 冒頭の `INCOME_CATS` / `EXPENSE_CATS` を書き換えると変更できます
- 配色は `index.html` の `<style>` 内、`:root` の CSS変数（`--pink` や `--blue` など）を変えると全体に反映されます
