# おかねびより

バイトのシフトと家計簿を、キャラクターと一緒に管理する自分用ミニアプリです。
サーバーやビルド不要、`index.html` を開くだけで動きます。データはブラウザの localStorage に保存されます（自分の端末だけに保存されるので、他の人には見えません）。

## ファイル構成

- `index.html` / `home.js` … **ホーム画面**。キャラクターのイラストと一緒に、今日の予定・所持金・次の給料日などをひと目で確認できるダッシュボードです
- `app.html` / `app.js` … **カレンダー＆家計簿アプリ本体**。月・週カレンダー、シフト入力、家計簿(月次/年次)、設定はこちらにあります
- `README.md` … このファイル

どちらのページも同じデータ（同じ端末のブラウザの localStorage）を見ているので、どちらで入力しても両方に反映されます。ホーム画面下部のナビゲーションから `app.html` の各タブへ移動できます。

## できること

**ホーム画面**
- 自分でアップロードしたキャラクターのイラストを背景に表示（画像は自動で縮小してから保存されます）
- キャラクターの「イメージカラー」を1色選ぶだけで、画面全体のアクセントカラーが自動で調整されます
- 今日の予定（シフト・予定）、所持金、今月の収支、次の給料日、お知らせを一覧表示
- 記録した件数に応じて「Lv」が上がる、ちょっとしたおまけ要素つき

**カレンダー＆家計簿アプリ（app.html）**
- 月カレンダー / 週タイムライン：シフト・予定・給料日・収支がひと目でわかる
- シフト入力 → 自動で給料計算、「締め日・支払日」の設定から給料日も自動算出
- よく使うシフトパターンの記憶、直前の入力内容の自動保持
- シフト・予定・収支はあとから編集・削除が可能
- 家計簿は月表示・年表示（カテゴリ別内訳つき）、経費フラグでの絞り込みに対応
- 各カレンダー・家計簿画面に「今日 / 今週 / 今月 / 今年」に戻るボタンあり
- 設定画面からJSONで書き出し・読み込み（バックアップ）が可能

## GitHub Pages での公開方法

1. GitHubで新しいリポジトリを作成する（例：`okane-biyori`）
2. このフォルダの中身（`index.html`, `home.js`, `app.html`, `app.js`, `README.md`）をリポジトリのルートに置いて push する

   ```bash
   git init
   git add .
   git commit -m "add okane-biyori app"
   git branch -M main
   git remote add origin https://github.com/【あなたのユーザー名】/okane-biyori.git
   git push -u origin main
   ```

3. GitHubのリポジトリページで **Settings → Pages** を開く
4. 「Build and deployment」の **Source** を `Deploy from a branch` にし、Branch を `main` / `/(root)` に設定して **Save**
5. 数分待つと `https://【あなたのユーザー名】.github.io/okane-biyori/` でアクセスできるようになります（`index.html` ＝ホーム画面が最初に開きます）

> ローカルで試したいだけなら `index.html` をブラウザでダブルクリックして開くだけでOKです。

## 最初にやること

1. ホーム画面右上の ⚙️ から「キャラクター設定」を開き、イラストの追加・キャラクターの名前・イメージカラー・所持金の初期値を設定してください
2. `app.html` の「設定」タブで、バイトの時給・締め日・支払日を自分のバイト先に合わせて設定してください

## データについて

- データ（シフト・予定・家計簿・キャラクター設定・イラスト画像）はすべて端末のブラウザ内（localStorage）だけに保存されます。ブラウザのデータを消去すると失われるので、たまに `app.html` の設定画面から「JSONで書き出す」でバックアップしておくと安心です（イラスト画像もJSONに含まれます）
- スマホとPCなど複数端末で使いたい場合は、書き出したJSONをもう一方の端末で「JSONを読み込む」から読み込んでください（自動同期はしません）

## カスタマイズのヒント

- 収入・支出のカテゴリは `app.js` 冒頭の `INCOME_CATS` / `EXPENSE_CATS` を書き換えると変更できます
- ホーム画面のおまけ要素（Lv計算やお知らせの条件）は `home.js` の `renderLevel` / `renderNotices` を書き換えると調整できます
- 配色の土台（背景の濃紺など）は `index.html` の `:root` にある `--bg0` 〜 `--bg2` を変えると変更できます（アクセントカラーはキャラクター設定から選ぶ色で自動計算されます）
